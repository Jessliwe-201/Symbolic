#Symbolic

Тёмный ASCII/Braille-редактор с импортом фото, экспортом для Discord

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)

## Возможности

- **Рисование мышкой** — ЛКМ рисует, ПКМ стирает
- **10 наборов символов** — классика, блоки `█▓▒░`, эмодзи, звёзды
- **Импорт фото → ASCII** — любая картинка превращается в арт
- **Braille-режим** — в 8 раз детальнее ASCII, идеально для Steam
- **Обрезка краёв** и **уменьшение ×2 / ×3** — подгонка под лимиты
- **Экспорт в текст** — с неразрывными пробелами
- **Копировать для Discord** — с проверкой лимита
- **Тёмная тема** — приятно для глаз

##  Как пользоваться

### Ручное рисование

1. Выбери символ в поле **«Символ»** (или введи свой)
2. Выбери размер кисти
3. **ЛКМ** — рисовать, **ПКМ** — стирать
4. **«Как текст»** — посмотреть результат
5. **«Копировать для Discord»** — сразу в буфер с ` ``` `

### Импорт фото

1. Нажми **«📷 Фото → ASCII»** — обычный ASCII-арт
2. Или **«📷 Braille»** — плотный арт из точек (для Steam)

### Для Steam профиля

1. Импортируй Braille-фото
2. Нажми **×2** → холст ~47 символов ширины
3. **«Обрезать края»**
4. **«Как текст»** → скопируй
5. Вставь в **Custom Info Box** профиля

⚠️ Steam считает **байты**, а не символы. Лимит ~1000 байт.
Braille-символ = 3 байта → влезает ~330 символов.
